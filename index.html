Tilts or moves the whole object in local 3D space. This is single-object 3D; multi-layer scene approaches are described below.

3D layering approaches

1. Single transformed object — implemented now. Treat the whole object as one plane and animate Rotate X/Y/Z, Translate Z and Perspective. Simple and predictable, but internal content stays flat.

2. Child layer stack. Let one stage object contain named sub-layers, each with its own local Z offset. Good for cards, mock device screens and parallax without turning the whole stage into a scene graph.

3. 3D object group / scene graph. Create a parent object with shared position/rotation/perspective and multiple child stage objects at independent X/Y/Z coordinates. Most powerful and best for true spatial scenes, but introduces hierarchy, group selection, inherited transforms and more complex hit-testing.

4. Visual-only pseudo layers. Generate decorative front/back/shadow faces from one object using CSS/pseudo-elements. Cheap and useful for thickness, but those layers are not independently authorable or interactive.

Why named states, not “in / out”?

An object can be background on Home, focused in Room and docked in Cloud. The state owns the destination; the transition and layout effect describe how it arrives there.
